# 供应中断事件的父类只来自子类公理

基础事实导出事件表中的具体类型。订单复核规则匹配供应中断事件，这个父类只在加载了子类公理之后成立。等价 SQL 手写枚举同一批具体类型，用来对照同一批订单。

把 `rdfs:domain` 放到供应中断事件上，会在去掉子类公理后仍然推出父类，移除继承实验随之失效。在基础事实查询里写死某一种具体类型，则下一种具体类型无法原样进入推理。本轮不新增第二种具体事件，也不做 SQL 与子类公理的程序对账；两边今天都只有交付暂停事件，由现有 SQL 结果是否仍为订单 101 来发现偏离。

排除无关类型时，只去掉 `rdf:`、`rdfs:`、`owl:` 命名空间里的类型。事件表中的具体类型一律保留。供应中断事件若已经出现在基础事实里，计算失败，而不是在查询里把它删掉。
