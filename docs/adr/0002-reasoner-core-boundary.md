# 推理计算与展示、实验断言分离

可复用的核心从 Ontop 拉取基础事实，加载本体，执行类型推理和业务规则，并返回结构化结果。调用方传入端点、查询、本体、规则，以及是否移除继承公理。核心不解析命令行，也不打印。返回的结构要能重放现有四段终端输出，并带上现有 `RESULT_JSON` 的字段。

CLI 根据这个结构打印现有输出，并保持现有退出码。`--expect` 在核心之外比对命中订单。服务拉取失败、基础事实为空，以及基础事实里提前出现父类，仍由核心抛出，再由 CLI 映射到原来的退出码。

本轮不增加 HTTP、MCP、自然语言或 Agent。以后这些入口直接调用同一核心，不解析终端输出，也不依赖 `--expect`。拉取放在核心里，是为了让这些失败只有一处语义。终端展示和实验断言留在核心外面。
