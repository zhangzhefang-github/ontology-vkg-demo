# 同一订单和事件只占一条建议

供应风险复核任务对应一条 R-01 规则应用，也就是一张采购订单和一个供应中断事件。决策记录以（订单, 事件）占位：待审批、尚未被阻止的已批准、已拒绝占住这个位置；已失效和执行被阻止释放占位。

拒绝是采购主管的终局，占位不释放，同一组合不能再建议。失效只说明当时的证据已经不能用。占位释放以后可以重新建议，但必须重新审批。按订单一条任务、把多个事件并进同一份证据，会让新事件去改已有任务。拒绝后允许再建议，则会让再次提交绕过已经做出的拒绝。

占位用唯一约束实现，释放时把占位列置空。MySQL 的唯一索引允许多个空值，因此同一组合可以留下多条已失效或已阻止的记录。
